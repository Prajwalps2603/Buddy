Takes a minute

Install in four steps

  1. Download

    Tap Download for Android on your phone.

  2. Open the file

    Open Buddy-1.0.0.apk from your notifications or Downloads.

  3. Allow the install

    If asked, allow your browser to install unknown apps, then tap Install. If Play Protect warns you, tap More details → Install anyway. It does this for any app that isn’t from the Play Store.

  4. Sign in with Google

    Buddy sets up its private workspace in your Drive. Your first passkey is your name without spaces; change it in Profile.
